Section 3.1အခန်းခွဲ 3.1

Oxidation numbersOxidation number များ

The oxidation number (or oxidation state) of an atom shows how many electrons it has lost or gained compared with the neutral atom. It can be zero, positive or negative.

Atom တစ်ခုရဲ့ oxidation number (သို့) oxidation state ဆိုတာ neutral atom နဲ့ နှိုင်းယှဉ်ရင် electron ဘယ်နှစ်လုံး ဆုံးရှုံး (သို့) ရရှိထားသလဲ ဆိုတာကို ပြပါတယ်။ သုည၊ အပေါင်း (သို့) အနုတ် ဖြစ်နိုင်ပါတယ်။

Positive oxidation numberအပေါင်း oxidation number

The atom has fewer electrons than the neutral atom. In NaCl, sodium is +1.

Atom မှာ neutral atom ထက် electron နည်းပါတယ်။ NaCl မှာ sodium က +1 ဖြစ်ပါတယ်။

Negative oxidation numberအနုတ် oxidation number

The atom has more electrons than the neutral atom. In NaCl, chlorine is −1.

Atom မှာ neutral atom ထက် electron များပါတယ်။ NaCl မှာ chlorine က −1 ဖြစ်ပါတယ်။

Sodium gives one electron to chlorineSodium က chlorine ကို electron ၁ လုံး ပေးလိုက်ပါတယ်

Rules for assigning oxidation numbersOxidation number သတ်မှတ်ရာတွင် စည်းမျဉ်းများ

  1. Every element on its own has oxidation number 0, whether it is monoatomic, diatomic or triatomic (Cu, He, H2, O2, I2, F2, O3).
  2. In a neutral molecule, the oxidation numbers add up to 0 (KMnO4, NaCl).
  3. In a polyatomic ion, the oxidation numbers add up to the charge on the ion (MnO4^-, NH4^+).
  4. Hydrogen is +1, except in metal hydrides where it is −1 (NaH, LiH, CaH2).
  5. Oxygen is −2, except in peroxides where it is −1 (H2O2, BaO2, Na2O2) and in OF2 where it is +2.
  6. Metals in ionic compounds are positive. Alkali metals are +1 and alkaline earth metals are +2.
  7. Halogens are −1 in compounds such as BaCl2, NaBr, KI. In interhalogens (BrF3, IF7, ClF3) and oxygen compounds (KClO3, NaOCl) the halogen is positive.
  8. In covalent compounds, the negative oxidation number goes to the more electronegative atom.
  1. Element တစ်မျိုးတည်း သီးသန့်ရှိရင် monoatomic၊ diatomic (သို့) triatomic ဖြစ်ပါစေ oxidation number 0 ဖြစ်ပါတယ် (Cu, He, H2, O2, I2, F2, O3)။
  2. Neutral molecule တစ်ခုမှာ oxidation number များ ပေါင်းလဒ် 0 ဖြစ်ပါတယ် (KMnO4, NaCl)။
  3. Polyatomic ion တစ်ခုမှာ oxidation number များ ပေါင်းလဒ်ဟာ ion ရဲ့ charge နဲ့ ညီပါတယ် (MnO4^-, NH4^+)။
  4. Hydrogen က +1 ဖြစ်ပြီး metal hydride တွေမှာတော့ −1 ဖြစ်ပါတယ် (NaH, LiH, CaH2)။
  5. Oxygen က −2 ဖြစ်ပြီး peroxide တွေမှာ −1 (H2O2, BaO2, Na2O2) နဲ့ OF2 မှာ +2 ဖြစ်ပါတယ်။
  6. Ionic compound ထဲက သတ္တုတွေဟာ အပေါင်း ဖြစ်ပါတယ်။ Alkali metal တွေက +1၊ alkaline earth metal တွေက +2 ဖြစ်ပါတယ်။
  7. Halogen တွေဟာ BaCl2, NaBr, KI လို compound တွေမှာ −1 ဖြစ်ပါတယ်။ Interhalogen (BrF3, IF7, ClF3) နဲ့ oxygen ပါတဲ့ compound (KClO3, NaOCl) တွေမှာတော့ halogen က အပေါင်း ဖြစ်ပါတယ်။
  8. Covalent compound တွေမှာ အနုတ် oxidation number ကို electronegativity ပိုများတဲ့ atom က ယူပါတယ်။

Three steps to find an oxidation numberOxidation number ရှာရန် အဆင့် ၃ ဆင့်

  1. Write the oxidation number of each known atom below its symbol.သိပြီးသား atom တစ်ခုချင်းရဲ့ oxidation number ကို သင်္ကေတ အောက်မှာ ရေးပါ။
  2. Multiply each oxidation number by the number of atoms of that element.Oxidation number တစ်ခုချင်းကို အဲဒီ element ရဲ့ atom အရေအတွက်နဲ့ မြှောက်ပါ။
  3. Write the sum and set it equal to 0 for a compound, or to the charge for an ion. Solve for the unknown.ပေါင်းလဒ်ကို compound ဆိုရင် 0၊ ion ဆိုရင် charge နဲ့ ညီအောင် ရေးပြီး မသိကိန်းကို ရှာပါ။

Section 3.2အခန်းခွဲ 3.2

Concepts of oxidation and reductionOxidation နှင့် reduction အယူအဆများ

Oxidation and reduction can be described in four ways: by oxygen, by hydrogen, by electrons, or by oxidation numbers. Each newer definition covers more reactions than the one before.

Oxidation နဲ့ reduction ကို နည်း ၄ မျိုးနဲ့ ဖော်ပြနိုင်ပါတယ်: oxygen၊ hydrogen၊ electron (သို့) oxidation number အပေါ် အခြေခံပြီး ဖြစ်ပါတယ်။ နောက်ပိုင်း အဓိပ္ပာယ်ဖွင့်ဆိုချက်တွေက ဓာတ်ပြုမှု ပိုများများကို အကျုံးဝင်ပါတယ်။

Oxidation: gain of oxygenOxidation: oxygen ရခြင်း

In lightning, nitrogen gains oxygen, so nitrogen is oxidised to nitrogen oxide.

လျှပ်စီးလက်ချိန်မှာ nitrogen က oxygen ရလို့ nitrogen oxide အဖြစ် oxidise ဖြစ်ပါတယ်။

N2 (g) + O2 (g) → 2NO (g)

Reduction: loss of oxygenReduction: oxygen ဆုံးခြင်း

Heated with coke, copper(II) oxide loses oxygen, so it is reduced to copper.

Coke နဲ့ အပူပေးတဲ့အခါ copper(II) oxide က oxygen ဆုံးလို့ copper အဖြစ် reduce ဖြစ်ပါတယ်။

2CuO (s) + C (s) → 2Cu (s) + CO2 (g)

Oxidation: loss of hydrogenOxidation: hydrogen ဆုံးခြင်း

Hydrogen sulphide loses hydrogen, so it is oxidised.

Hydrogen sulphide က hydrogen ဆုံးလို့ oxidise ဖြစ်ပါတယ်။

Cl2 (g) + H2S (g) → S (s) + 2HCl (g)

Reduction: gain of hydrogenReduction: hydrogen ရခြင်း

Chlorine gains hydrogen, so it is reduced.

Chlorine က hydrogen ရလို့ reduce ဖြစ်ပါတယ်။

H2 (g) + Cl2 (g) → 2HCl (g)

Oxygen is an electronegative element and hydrogen is electropositive, so the definitions extend to them: adding an electronegative element is oxidation, adding an electropositive element is reduction.

Oxygen က electronegative element ဖြစ်ပြီး hydrogen က electropositive element ဖြစ်ပါတယ်။ ဒါကြောင့် electronegative element ထပ်ပေါင်းခြင်းကို oxidation၊ electropositive element ထပ်ပေါင်းခြင်းကို reduction လို့ ချဲ့ထွင် သတ်မှတ်ပါတယ်။

Many redox reactions involve no oxygen or hydrogen at all. Here zinc gives two electrons to a copper(II) ion.

Redox ဓာတ်ပြုမှု အများအပြားမှာ oxygen (သို့) hydrogen လုံးဝ မပါပါဘူး။ ဒီမှာ zinc က copper(II) ion ကို electron ၂ လုံး ပေးပါတယ်။

Zn (s) + Cu^2+ (aq) → Zn^2+ (aq) + Cu (s)
Zn (s) → Zn^2+ (aq) + 2e^-  loss of electrons: oxidationelectron ဆုံးခြင်း: oxidation
Cu^2+ (aq) + 2e^- → Cu (s)  gain of electrons: reductionelectron ရခြင်း: reduction

Memory aid: OIL RIG. Oxidation Is Loss, Reduction Is Gain (of electrons).

မှတ်ရန်: OIL RIG။ Oxidation Is Loss (electron ဆုံး)၊ Reduction Is Gain (electron ရ)။

An element whose oxidation number increases is oxidised. An element whose oxidation number decreases is reduced.

Oxidation number တိုးလာတဲ့ element က oxidise ဖြစ်ပြီး oxidation number လျော့သွားတဲ့ element က reduce ဖြစ်ပါတယ်။

P4 + 5O2 + 6H2O → 4H3PO4

Phosphorus: 0 → +5, oxidised.Phosphorus: 0 → +5၊ oxidise ဖြစ်။ Oxygen (from O2): 0 → −2, reduced.Oxygen (O2 မှ): 0 → −2၊ reduce ဖြစ်။

All four definitions togetherအဓိပ္ပာယ်ဖွင့်ဆိုချက် ၄ မျိုး စုစုပေါင်း

In terms ofအခြေခံချက်OxidationReduction

Section 3.3အခန်းခွဲ 3.3

Redox reactionsRedox ဓာတ်ပြုမှုများ

Oxidation and reduction always happen together. If one substance loses electrons, another must gain them. Reactions with both processes are called redox reactions, and the two separate parts are called half-reactions.

Oxidation နဲ့ reduction ဟာ အမြဲတမ်း အတူတကွ ဖြစ်ပါတယ်။ Substance တစ်ခုက electron ဆုံးရင် နောက်တစ်ခုက ရရပါမယ်။ နှစ်မျိုးလုံး ပါဝင်တဲ့ ဓာတ်ပြုမှုကို redox reaction လို့ ခေါ်ပြီး သီးခြားအပိုင်း ၂ ခုကို half-reaction လို့ ခေါ်ပါတယ်။

Burning magnesium ribbonMagnesium ပြား လောင်ကျွမ်းခြင်း

Magnesium (2.8.2) gives its two outer electrons to oxygen (2.6). Both end up with a full outer shell of eight.

Magnesium (2.8.2) က အပြင်ဘက် electron ၂ လုံးကို oxygen (2.6) ကို ပေးပါတယ်။ နှစ်ခုလုံး အပြင်ဆုံး shell မှာ electron ၈ လုံး ပြည့်သွားပါတယ်။

Mg → Mg^2+ + 2e^-  oxidation, loss of electronsoxidation၊ electron ဆုံးခြင်း
½O2 + 2e^- → O^2-  reduction, gain of electronsreduction၊ electron ရခြင်း

    Chemistry in societyလူ့အဖွဲ့အစည်းထဲက ဓာတုဗေဒ

    Burning petrol, gas and wood is oxidation that releases the energy we use every day.ဓာတ်ဆီ၊ ဂက်စ် နဲ့ ထင်း လောင်ကျွမ်းခြင်းဟာ နေ့စဉ် သုံးတဲ့ စွမ်းအင်ကို ထုတ်ပေးတဲ့ oxidation ဖြစ်ပါတယ်။

    Oxidation of food in the body releases energy for biochemical reactions.ခန္ဓာကိုယ်ထဲမှာ အစာ oxidise ဖြစ်ခြင်းက biochemical ဓာတ်ပြုမှုတွေအတွက် စွမ်းအင် ထုတ်ပေးပါတယ်။

    Oxidation of fats and oils causes rancidity, and oxidation turns cut apples brown.အဆီနဲ့ ဆီတွေ oxidise ဖြစ်ရင် ပုပ်သွားပြီး လှီးထားတဲ့ ပန်းသီးတွေလည်း oxidation ကြောင့် ညိုသွားပါတယ်။

    Margarine is made by reducing (adding hydrogen to) oils from corn, peanuts and soybeans.Margarine ကို ပြောင်း၊ မြေပဲ နဲ့ ပဲပိစပ်ဆီတွေကို reduce လုပ်ပြီး (hydrogen ထည့်ပြီး) ပြုလုပ်ပါတယ်။

    Breathalysers estimate alcohol in a driver’s breath using a redox reaction.Breathalyser တွေက redox ဓာတ်ပြုမှုကို သုံးပြီး ယာဉ်မောင်းရဲ့ အသက်ရှူထဲက အရက်ပမာဏကို ခန့်မှန်းပါတယ်။

    Oxidising and reducing agents purify water, bleach fabrics and store energy in batteries and fuel cells.Oxidising agent နဲ့ reducing agent တွေကို ရေသန့်စင်ခြင်း၊ အထည် အရောင်ချွတ်ခြင်း နဲ့ ဘက်ထရီ၊ fuel cell တွေမှာ စွမ်းအင် သိုလှောင်ခြင်းတို့အတွက် သုံးပါတယ်။

    Section 3.4အခန်းခွဲ 3.4

    Oxidising and reducing agentsOxidising agent နှင့် reducing agent

    In every redox reaction, one substance causes the other to change. The agent does to others the opposite of what happens to itself.

    Redox ဓာတ်ပြုမှုတိုင်းမှာ substance တစ်ခုက နောက်တစ်ခုကို ပြောင်းလဲစေပါတယ်။ Agent ဟာ တခြားအရာကို သူကိုယ်တိုင် ဖြစ်တာနဲ့ ဆန့်ကျင်ဘက် ဖြစ်စေပါတယ်။

    Oxidising agent (oxidant)

    Accepts electrons and is reduced itself. It helps the other substance get oxidised. It is usually in one of its higher oxidation states.

    Electron လက်ခံပြီး သူကိုယ်တိုင် reduce ဖြစ်ပါတယ်။ တခြား substance ကို oxidise ဖြစ်အောင် ကူညီပါတယ်။ များသောအားဖြင့် oxidation state မြင့်တဲ့ အခြေအနေမှာ ရှိပါတယ်။

    Examples: oxygen, halogens, concentrated sulphuric acid, nitric acid, hydrogen peroxide, potassium permanganate, potassium dichromate, metal oxides.

    ဥပမာ: oxygen၊ halogen များ၊ concentrated sulphuric acid၊ nitric acid၊ hydrogen peroxide၊ potassium permanganate၊ potassium dichromate၊ metal oxide များ။

    Reducing agent (reductant)

    Donates electrons and is oxidised itself. It helps the other substance get reduced. It is usually in one of its lower oxidation states.

    Electron ပေးပြီး သူကိုယ်တိုင် oxidise ဖြစ်ပါတယ်။ တခြား substance ကို reduce ဖြစ်အောင် ကူညီပါတယ်။ များသောအားဖြင့် oxidation state နိမ့်တဲ့ အခြေအနေမှာ ရှိပါတယ်။

    Examples: carbon, carbon monoxide, sulphur dioxide, hydrogen sulphide, hydrogen, metals.

    ဥပမာ: carbon၊ carbon monoxide၊ sulphur dioxide၊ hydrogen sulphide၊ hydrogen၊ သတ္တုများ။

    The redox seesawRedox ဒိန်းခုံ (seesaw)

    The reducing agent gives an electron and goes up in oxidation number. The oxidising agent takes it and goes down.

    Reducing agent က electron ပေးပြီး oxidation number တိုးလာပါတယ်။ Oxidising agent က electron ယူပြီး oxidation number လျော့သွားပါတယ်။

    Magnesium and copper(II) oxideMagnesium နှင့် copper(II) oxide

    Mg (s) + CuO (s) → Cu (s) + MgO (s)

    Mg: 0 → +2. Magnesium loses electrons, so it is oxidised and is the reducing agent.
    Cu: +2 → 0. Copper(II) oxide gains electrons, so it is reduced and is the oxidising agent.

    Mg: 0 → +2။ Magnesium က electron ဆုံးလို့ oxidise ဖြစ်ပြီး reducing agent ဖြစ်ပါတယ်။
    Cu: +2 → 0။ Copper(II) oxide က electron ရလို့ reduce ဖြစ်ပြီး oxidising agent ဖြစ်ပါတယ်။

    Sort the substancesSubstance များကို ခွဲခြားပါ

    Is each one usually an oxidising agent or a reducing agent?တစ်ခုချင်းဟာ များသောအားဖြင့် oxidising agent လား reducing agent လား?

    Identify the agentsAgent များကို ဖော်ထုတ်ပါ

    Work it out first, then open each reaction to check.အရင် ကိုယ်တိုင် စဉ်းစားပြီးမှ ဓာတ်ပြုမှု တစ်ခုချင်းကို ဖွင့်ကြည့်ပါ။

    Section 3.5အခန်းခွဲ 3.5

    Balancing redox equationsRedox ညီမျှခြင်း ချိန်ညှိခြင်း

    A balanced equation is needed for any calculation. Simple redox equations can be balanced by inspection, but reactions in solution need a method. Pick a worked example and go through it one step at a time.

    တွက်ချက်မှု မှန်သမျှအတွက် ချိန်ညှိပြီးသား ညီမျှခြင်း လိုအပ်ပါတယ်။ ရိုးရှင်းတဲ့ redox ညီမျှခြင်းတွေကို ကြည့်ရုံနဲ့ ချိန်ညှိနိုင်ပေမယ့် solution ထဲက ဓာတ်ပြုမှုတွေအတွက် နည်းလမ်း လိုပါတယ်။ ဥပမာ တစ်ခု ရွေးပြီး တစ်ဆင့်ချင်း လိုက်ကြည့်ပါ။

      Acidic or alkaline?Acidic လား alkaline လား?

      In acidic solution, balance O with H₂O and H with H⁺. In alkaline solution, do the same, then add OH⁻ to both sides so that H⁺ + OH⁻ → H₂O.

      Acidic solution မှာ O ကို H₂O နဲ့၊ H ကို H⁺ နဲ့ ချိန်ညှိပါ။ Alkaline solution မှာလည်း အတူတူ လုပ်ပြီး H⁺ + OH⁻ → H₂O ဖြစ်အောင် OH⁻ ကို နှစ်ဖက်လုံး ထည့်ပါ။

      Half-equation method: the order to followHalf-equation နည်း: လိုက်နာရမည့် အစီအစဉ်

      1. Write the unbalanced equation in ionic form.
      2. Write separate half-reactions for oxidation and reduction.
      3. Balance atoms other than O and H.
      4. Balance O by adding H2O.
      5. Balance H by adding H^+ ions.
      6. Balance the charge of each half-equation with electrons.
      7. Multiply so both half-equations have the same number of electrons.
      8. Add the half-equations and cancel electrons and common terms. In alkaline solution, add OH^- to both sides to turn H^+ into water.
      1. ချိန်ညှိရသေးတဲ့ ညီမျှခြင်းကို ionic ပုံစံဖြင့် ရေးပါ။
      2. Oxidation နဲ့ reduction အတွက် half-reaction တွေကို သီးခြားစီ ရေးပါ။
      3. O နဲ့ H မဟုတ်တဲ့ atom တွေကို ချိန်ညှိပါ။
      4. H2O ထည့်ပြီး O ကို ချိန်ညှိပါ။
      5. H^+ ion ထည့်ပြီး H ကို ချိန်ညှိပါ။
      6. Half-equation တစ်ခုချင်းရဲ့ charge ကို electron နဲ့ ချိန်ညှိပါ။
      7. Half-equation နှစ်ခုလုံးမှာ electron အရေအတွက် တူအောင် မြှောက်ပါ။
      8. Half-equation တွေကို ပေါင်းပြီး electron နဲ့ တူညီတဲ့ အရာတွေကို ချေဖျက်ပါ။ Alkaline solution မှာဆိုရင် H^+ ကို ရေ ဖြစ်အောင် OH^- ကို နှစ်ဖက်လုံး ထည့်ပါ။
